# Exemple de profil Java organisationnel

Ce profil illustratif remplace le générique uniquement après signature administrative.
Utiliser Java 21, Maven et le wrapper. Documenter classes et méthodes avec leurs exigences réelles. Valider les entrées aux frontières. Couvrir les invariants métier et les comportements d'erreur par des tests. Garder les identifiants hors des sources.

Exigences : DEVAI-005, DEVAI-137, DEVAI-162, DEVAI-164.
