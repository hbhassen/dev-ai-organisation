# ODS 0.3.0

Start with [installation](docs/INSTALLATION.md), [configuration](docs/CONFIGURATION.md), [validation](docs/VALIDATION.md) and [requirement coverage](docs/CONFORMITE.md).

This is a development delivery; consult BUILD.json for its exact source identity and SHA256SUMS for artifact digests.
