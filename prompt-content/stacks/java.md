# Profil Java générique
Origine : GENERIC. Exigences : DEVAI-005, DEVAI-048, DEVAI-137, DEVAI-162, DEVAI-163, DEVAI-197.

Utiliser Java 21 uniquement pour les composants et builds d'ODS. `ods.javaPath` choisit le Java du moteur ODS ; il ne configure pas le JDK d'un projet ouvert. Pour un projet Java existant, respecter son `pom.xml` (`java.version`, `maven.compiler.release`), ses Maven Toolchains, son Maven Wrapper et ses instructions. Pour une commande demandée comme `mvn clean install`, utiliser le Maven installé visible depuis l'extension et conserver le `PATH` et `JAVA_HOME` du poste ; vérifier le runtime Maven avec `mvn -version`. Ne jamais ajouter `-Djava.version=21` ou `-Dmaven.compiler.release=21`, ni modifier le POM vers Java 21, uniquement pour satisfaire DEVAI-005. Si le JDK réellement utilisé ne respecte pas le projet, expliquer le conflit et attendre une décision au lieu de changer sa configuration. Une commande explicitement demandée par l'utilisateur ne nécessite pas une seconde demande d'autorisation.

Pour les composants ODS, respecter la version Spring Boot qualifiée et conserver Maven. Pour un projet existant, conserver ses frameworks et son système de build. Séparer domaine, cas métier et adaptateurs. Valider les entrées à la frontière ; utiliser des exceptions explicites sans exposer de secrets. Éviter état global mutable et dépendances inutiles. Ajouter une Javadoc utile à chaque classe, record, interface, constructeur et méthode avec les références DEVAI pertinentes. Écrire des assertions métier, couvrir limites et refus, puis exécuter le build complet demandé. Ne pas désactiver des tests pour réussir le build.
