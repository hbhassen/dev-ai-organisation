# Profil Angular générique
Origine : GENERIC. Exigences : DEVAI-049, DEVAI-137, DEVAI-162, DEVAI-163.

Utiliser la CLI officielle et une matrice Angular/Node/TypeScript compatible. Respecter les composants, services et routes du projet. Préférer le typage strict et les entrées validées. Prévoir états de chargement, vide, refus et erreur. Respecter thèmes, clavier, labels accessibles et focus. Ne pas injecter de HTML non fiable ; traiter les données externes comme non fiables. Documenter classes et méthodes avec JSDoc/TSDoc et références. Ajouter les tests ciblés et exécuter les scripts de build et test existants sans supposer un outil de lint installé.
