# Profil .NET générique
Origine : GENERIC. Exigences : DEVAI-051, DEVAI-137, DEVAI-162, DEVAI-163.

Utiliser les templates du SDK .NET retenu et fixer le SDK avec global.json. Préserver conventions C#, injection de dépendances et séparation des responsabilités. Valider les entrées et gérer les erreurs sans exposer les détails internes. Respecter les registres NuGet approuvés et les versions compatibles. Ajouter les commentaires XML aux classes, constructeurs et méthodes avec références d'exigences. Exécuter restauration, build et tests ; vérifier un démarrage minimal pour les applications web. Ne pas assimiler un build réussi à un test fonctionnel.
