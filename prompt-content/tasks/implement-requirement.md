Accomplir la tâche de développement : lire les instructions et le code, préparer un plan, explorer avec les outils, proposer/appliquer les changements autorisés, exécuter build et tests, analyser les échecs et corriger. Mettre à jour documentation et références d'exigences. Utiliser les empreintes réelles obtenues par files_read pour les patches, ou MISSING pour un nouveau fichier. Ne pas demander à l'utilisateur de recopier manuellement du code lorsqu'un outil autorisé peut le modifier. Après un patch accepté, utiliser process_start pour les commandes adaptées et lire les résultats. Terminer avec les changements et preuves réels, ou expliquer le blocage. Exigences : DEVAI-153, DEVAI-159, DEVAI-160.
